The Source Code

The engine this project builds on, codenamed Poseidon, traces back to Bohemia Interactive's own opened engine source release, licensed GPL-3.0-or-later with additional Section 7 terms. That upstream engine snapshot is locked: it stays fixed at that release, and all further development happens downstream. Uslu dur! is the total-overhaul project built on top of that engine. The AI/engine rework plans and the flagship Guerrilla Mode open-world insurgency game mode live in this project's own tree, layered over the locked upstream snapshot. Build it with Clang + CMake + Ninja + vcpkg; see Under the Hood for the details.
