About Uslu dur!

What Is It, Exactly?

Uslu dur! is a total game overhaul of ARMA: Cold War Assault, the title first released in 2001 as Operation Flashpoint: Cold War Crisis. Twelve engine and AI mod-plans rework how the AI fights and perceives the world, plus how it takes commands, culminating in Guerrilla Mode: a brand-new, persistent open-world insurgency game mode that doesn't exist in the original game at all. That is the subject of this portal.

None of it happens in a vacuum: it's built on top of Bohemia Interactive's own newly-opened engine source, internal codename "Poseidon."

QUOTE

"Bohemia Interactive is releasing it to the community that has kept this game alive for more than two decades — to study it, build on it, fix it, and create from it."
Source: README.md

We took that invitation literally. The upstream release is the actual proprietary engine source, opened up and modernized to C++20, built with CMake + Clang, targeting Windows x64 and Linux x64. On its own, though, it's just a faithfully-ported original game. The overhaul is everything this project adds on top: reworked AI tactics and perception, plus the whole Guerrilla Mode game loop built from new SQF and engine commands. See Gameplay Systems and The Design Loop for what that actually means.

A Note On Names

"Uslu dur!" is this project's own name, kept deliberately distinct from Bohemia's shorthand for its own upstream engine drop, "Cold War Assault Remastered" (codename Poseidon, upstream org BohemiaInteractive/CWR). That upstream repository is locked: pull requests aren't accepted there, and it won't be continuously updated. It also sidesteps the classic community fan mod that carried the "Cold War Rearmed" name for years, a different and unrelated project. Uslu dur! is this overhaul: the AI mod-plans and Guerrilla Mode built on top of Bohemia's upstream drop.

IMPORTANT

The upstream engine source is locked: issues there are accepted only for bugs in official Steam builds. The overhaul (mod-plans and Guerrilla Mode) is this project's own active development. A separate living continuation of the upstream engine also exists at ofpisnotdead-com/CWR-CE, for anyone chasing engine work rather than the overhaul.

Setting & Theme

The source tree is engine and tooling code with no fixed campaign narrative; that narrative lives in the separately licensed game-data package. The Cold War setting surfaces through Guerrilla Mode's own design:

  • The original title's 1985 Cold-War-gone-hot fiction, replayed as an open-ended insurgency rather than a fixed campaign.
  • Faction shorthand from the community design docs: GUER (Resistance) and CIV (civilians) against an occupying EAST or WEST faction. Full CWA game data ships rosters for all four sides.
  • Swappable factions & islands are a launch requirement for Guerrilla Mode: a new game begins by choosing the island plus the civilian, resistance, and occupying factions. Full CWA data covers all four canonical islands: Everon, Malden, Kolgujev, and Nogova. This is an active, living design (see Gameplay Systems).
