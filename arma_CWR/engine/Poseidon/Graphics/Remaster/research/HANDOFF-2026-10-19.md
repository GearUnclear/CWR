After seeing the integrated features the owner said "nearly no difference" and asked for a real **visual overhaul** in the **modern photoreal** direction: natural colours, deep atmosphere, crisp detail, strong sun and shade. ## 7. Gotchas learned the hard way (follow these)

- **Never resume a long workflow after editing it.** Resuming `wf_8a317645-622` and `wf_311066ec-3bc` re-ran finished agents live (cache misses), which wasted about 10M tokens once. Launch a small new workflow for the remaining phases instead.
- **Never SendMessage an agent that a workflow started.** It spawns a second copy outside the workflow, and both edit the same files. To change instructions: stop the workflow and start a new one.
- **Workflow agents can mistake the owner's latest chat message for their task.** It happened: three agents only "removed a note" and stopped. Put a TASK_FIRST line at the top of every prompt.
- **Game cleanup:** a global `Stop-Process PoseidonGame` is forbidden (other sessions run games). Use `D:\Arma_CWA\arma_CWR\tools\stop-owned-games.ps1 -DataDir <junction>`. When stopping a workflow, also stop its driver PowerShell, cmd and tri processes (match the junction name in their command line), or they keep starting games.
- **Machine budget:** about 4 games run at once machine-wide; builds should use `-j 8` or less when several run.
- **Subagent caches stay warm for only about 4 minutes** (owner, 2026-10-19). Keep every single wait an agent makes (a build, a capture run) under about 4 minutes, or run it in the background and check in at least every 3 minutes. A full engine build takes about 2.5 minutes on an idle machine. The full capture set took about 6 minutes in one game at a time; run up to 4 games at once (`tri test -j 4`, the machine budget), split the big Malden set, and shoot the vanilla Originals once and reuse them.
- **PowerShell 5.1 pitfalls:**
  - `>` writes UTF-16, so make patches with `git diff --binary --output=<file>`.
  - Commit with `git commit -F <file>`; `-m` here-strings with double quotes break.
  - Quote `'stash@{0}'`.
- Subagents have fabricated results before. Verify deliverables on disk, and look at the images yourself before showing the owner.
- The engine `.gitignore` ignores `*.md`: use `git add -f` for docs.
- `stash@{0}` "A4 WIP (perf) moved to scratch gr-A4" still exists. A4 has landed, so it can be dropped after confirming with the owner.
