@LoBo - The Lost Brothers Mod (merged into a single modfolder)
==============================================================
Assembled from the OFP.info archive ("LoBoOFP" download set),
cross-checked against files.ofpisnotdead.com and ofpr.info (OFP.info 2.5).
Target game: Operation Flashpoint / Arma: Cold War Assault v1.96

CONTENTS
--------
This @LoBo modfolder merges the entire Lost Brothers modset into one
placeable folder. No more manual install order - everything below is
already laid out in the standard OFP modfolder layout:

    @LoBo\
      addons\        124 .pbo files    - all factions, vehicles, weapons,
                                          sounds, islands (Lebanon, Sinai v1.5,
                                          Iran/Iraq), JAM, building packs
      Bin\           RESOURCE.bin + configBackup\Config.bin
      dta\           AltJogging, Backbone, Classic, NewStandReload,
                     Patrol animation sets + "down air crew" mission data
      Missions\      10 packed .pbo demo missions
                    (sinai, iran_iraq, Lebanon80, Noe, Intro)
      user missions\ 19 unpacked demo mission folders (move into your
                     ..\Users\<you>\Missions\ if you want to play them)
      docs\          original readmes, credits, preview JPGs,
                     Lebanon-bundled demo missions, and the archival
                     early-release jordanian_army (2002) that is superseded
                     by the 2007 Jordanian/Syrian Pack
      The_Lost_Brothers_Official_Readme2.doc
      README.txt     (this file)

HOW TO LAUNCH
-------------
Copy the entire @LoBo folder into your OFP / CWA game directory (next to
the existing Addons / @@Resistance folders), then start the game with the
mod flag:

    flashpoint.exe -mod=@LoBo
    (or  coldwarassault.exe -mod=@LoBo  for Arma: CWA)

Demo missions: the ones in Missions\ will appear in the Single Player ->
Missions list (filter by island: Lebanon80, sinai, iran_iraq, Noe, Intro).
The folders in user missions\ are unpacked - to use them, copy the
individual folders into your user missions directory
( ..\Users\<your Windows username>\Documents\ColdWarAssault\Users\<you>\
  Missions\ or the OFP equivalent), then launch the Editor.

REQUIRED GAME STATE
-------------------
- Operation Flashpoint: Resistance v1.96 (or Arma: Cold War Assault 1.96+).
- No further addons are required - all dependencies (JAM2 + JAM3_FIXED6,
  Sinai v1.5, Iran/Iraq, Lebanon islands, and the third-party building/
  object packs they share) are bundled inside this @LoBo folder.
