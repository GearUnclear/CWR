# Allowlist for .githooks/check_no_game_data.py (the game data and secrets guard).
#
# Format: one entry per line, # starts a comment.
#   path/to/file.ext   exact path: bypasses every rule except the secret scan
#   path/to/dir/       directory prefix (ends in /): bypasses the extension,
#                      forbidden-folder and magic-byte rules only; the 5 MB
#                      limit, the over-64 KB config/stringtable rule and the
#                      secret scan still apply
#
# Every entry needs a comment saying why it belongs. Bohemia game data and
# @LoBo data NEVER qualify, whatever the folder: no pbo, paa, p3d, wrp, sound,
# de-binarized config or stringtable taken from a game or mod install. Secrets
# are never allowlisted.
#
# Built 2026-10-26 from `check_no_game_data.py --tree <rev> --no-allowlist` over
# every kept origin branch, then sorted by provenance.
