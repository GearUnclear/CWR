WHAT I BUILT (tmp/video/fogwind/fable-2/tools/, numpy + scipy + ffmpeg only, nothing from agent 1's kit)
  fogflow.py <clip.mkv> [--from N --to M] [--static] [--amp] [--mp4]
    1. luma decode (ffmpeg gray, -vsync 0: without it the rawvideo muxer drops frames after a trim).
    2. camera: global sub-pixel shift per frame pair, phase correlation of the whole half-res frame
       (--static forces 0 for held-camera probes).
    3. per region (agent 1's five boxes, reused only so regions line up by name): all frames of a 32-frame
       chunk are warped (cubic) onto the chunk centre's pose, then every pixel's time series is split into
         hp  = above ~5 Hz at 60 fps (frame minus a sigma 1.5 frame smoothing)
         bp  = ~1.5..5 Hz (sigma 1.5 minus sigma 6)
       and spatially into
         LOW  = hp smoothed over 12 px  (the sheet: the original frame-wide pump lives here)
         MID  = hp band 3..24 px        (cell-scale blotches: wind, boil)
         FINE = hp below 3 px           (encode grain, fizz)
         SLOW = bp band 3..24 px        (slow boil / drift)
       Fog that changes without the camera explaining it is what survives the stabilisation; vanilla
       calibrates the floor the warp itself leaves at object edges.
    4. TRAVEL: the MID residual's normalised cross-correlation surface between frames t and t+1 (and t+2)
       is AVERAGED over all pairs of the clip. A travel that is the same every frame adds up; random boil
       cancels. v1 = peak lag (px/frame vs the scene), p1 = correlation there, TRAVEL = p1 minus the lag-0
       value, WIND = MID x TRAVEL. A real travel has v2 = 2 v1 at lag 2.
       Reading: p1 ~ 0 = fizz that changes every frame; TRAVEL high with |v1| > 0 = travelling structure
       (wind, or a screen-locked pattern under a pan, which travels at minus the camera); LOW high = pump.
    5. VIS = rms code values of MID / LOW / SLOW / FINE.
    --amp: amp_<label>.png = 2x crop of the bay + far valley, 4 consecutive frames stabilised to one pose
       with the >5 Hz residual x8 added back (wind and boil become visible to a human); xt_<label>.png =
       stabilised x-t strips of three fog rows (valley, bay, haze), time down.  --mp4: amp2x_<label>.mp4,
       the raw 2x crop with the residual x8 added, 60 fps, to watch at real speed.
  compare.py: one sheet, one row per clip, 3 consecutive frames of a x3 valley/shore crop with the residual
    x10 added, plus the plain frame and the residual alone x30 (held-camera clips only).
  table.py: one line per clip from out/*.json; verdict = TRAVEL <= 0.05 in every fog region, LOW <= 0.08,
    WIND <= 0.012 (vanilla: TRAVEL 0.02-0.03, LOW 0.05-0.075, WIND 0.005-0.010).
  run.sh <jobs file> <parallel>: batch driver; jobs_*.txt list what was run.
