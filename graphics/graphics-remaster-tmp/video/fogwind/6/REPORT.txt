THE DESIGN (shaders/S2, generator gen_shaders.py)
-------------------------------------------------
Three parts, one sample per cell as today (no extra injection cost):
 1. History read at the cell and slice CENTRE (psFogInject fogSlice): the jittered point is still
    sampled for this frame's value, but the reprojection for the history fetch uses the unjittered
    column (cell centre) and fogSliceDepth((s + 0.5) / N). The shipped code reprojects the jittered
    point, which makes the stored value a LEAKY SUM of the jitter (s_n = o_n + 0.88 s_{n-1}, gain
    1/(1-0.88) = 8.3) instead of its EMA (s_n = 0.12 o_n + 0.88 s_{n-1}). Golden-ratio sequence:
    residual rms 0.261 cell/slice (p2p 1.10) shipped vs 0.031 (p2p 0.13) with the centre read.
    Confirmed in the game by C0 (below): the centre read alone cuts the original pump 9x.
 2. A 2x2-PERIODIC antithetic jitter instead of a per-cell IGN offset: the four cells of each 2x2
    block take the four 90-degree rotations of r (cos t_n, sin t_n) in xy (diagonal cells opposite),
    and r cos(t_n + k pi/2 + pi/2 + 2.39996 s) in depth (k = the cell's place in the block, s the
    slice), r = sqrt(1/6) = 0.408 (a box's second moment per axis), t_n = 2 pi fogDepth.w (the
    frame's golden-ratio phase, so no new uniform). Per block and every frame: the offsets sum to 0,
    all odd moments are 0, the second moments (xx, yy, zz, and the mixed ones) are constant in time.
    A 2-periodic pattern cannot translate (agent 1's rule: no ramp in the cell index), so there is
    nothing that can read as wind; it can only stand.
 3. psFogIntegrate reads the injected volume through a 3x3 tent [1 2 1] x [1 2 1] / 16 in xy (four
    bilinear taps at +-0.5 cell, the slice centre in z; the volume is GL_LINEAR, clamp to edge). The
    tent's response at the 2x2 block's three frequencies is exactly 0, so the standing residual of
    any locally smooth medium cancels to first and second order every frame; bilinear history
    resampling under a pan maps a 2-periodic zero-mean pattern to another one, so it still cancels
    when the camera moves. The tent filters only what is displayed; the history is not filtered, so
    there is no feedback. No z blur is needed: the depth jitter's residual cancels in xy too (the
    depth gradient of the medium is the same in neighbouring columns).
AI link: the medium (ComputeFogMedium / FogMedium) is untouched; only how the renderer samples and
filters the volume changes, so AI sight still follows the rendered fog.

WHAT I RULED OUT OR FOUND ON THE WAY
  - The depth slice layout is not the lever: 64 exponential slices to the classic fog end keep the
    last slice at 6.5-9.5% of its depth (zFar 900 m: 59 m; 1500 m: 111 m; 3000 m: 259 m; 5000 m:
    474 m). More far slices cut the jitter error only linearly, at linear cost; the antithetic
    pattern cancels the depth residual in xy whatever the slice depth, so I did not pursue it.
  - A z blur is not needed for the cancellation (S2's xy tent already cancels the depth residual);
    it is useful only to restore the shipped look (S2z).
  - The tent alone on d91 (S1, toy model) weakens the wind but leaves it travelling.
  - An every-27-frame ~1 code value pulse on the far shoreline (x 1762-1800, y 669; frames 25, 51,
    79, 108) is present in the original, C0, d91 (frame 79), S2, S2z and S2h, and absent with the
    camera held: not from any jitter pattern; agent 2 sees it in every variant too. Source not
    identified (not a camera-path jerk: the measured shift is smooth there).

RISKS AND OPEN POINTS
  - The 2x2 cancellation is exact for a locally smooth medium; at hard edges (shadow edges in the
    haze, the mist top seen edge-on) a small standing residual is left over 1-2 cells. It cannot
    travel (2-periodic), and the static/moving numbers show nothing above the floor, but the pine
    probe class (hard canopy shadows in the air) was only checked by agent 3 on Act25 (not
    discriminating there: swaying foliage dominates).
  - The xy tent softens the volume by a kernel of 0.7 cell rms (12 px cells): not visible in the crops
    and offset by the absence of the jittered-history blur; the 3D tent (S2z) restores the base
    density. If the lead prefers Act25/S2h's history blur for the look, use plain S2's xy tent with
    it (S2h lands about +0.7..1.0 code mistier than base; a +-0.18 blur would centre it).
  - Production: t_n comes from fogDepth.w (already the golden-ratio phase), so no new uniform; the
    C++ comment at the jitter source and the unit test pinning fogCellNoise need updating; a unit
    test can check that the four rotations sum to zero and that the tent's response at (1/2,0),
    (0,1/2), (1/2,1/2) is 0.
